# 基础生活 | 钱 | 投资理财

## 首版使用

在“生活场景”进入同名项目。默认显示本人真实账户，初始没有虚构资金、产品或持仓。右上角可切换“合成演示”，演示只读，与真实记录隔离。

当前局域网入口：[打开投资理财工作台](http://10.5.2.31:5180/invest?project=255)。需登录具备该项目权限的账号；地址随本机局域网IP变化。

1. 账户总览：填写现金、应急、确定支出、负债还款预留、期限与亏损承受额。每月新增资金不提前计入可投金额。
2. 基金 / ETF 对比：选择类别和同类组，勾选档案，用相同金额、持有期限比较费用与资料。股票与直接债券支持档案查询和观察，不进行自动候选排序。
3. 候选解释：按资金、风险、期限、资料、回撤与ETF折溢价过滤，最多三个同类研究候选。每个候选附收益逻辑、风险、已知重叠、执行条件、复核事件及来源。
4. 购买入口：复制真实代码，进入本人已开户的正规渠道。官方入口与公告研究入口分别标注，程序不下单。
5. 收益复盘：导入完整账户估值与外部净流入，计算盈亏、TWR、XIRR及观察点回撤；可导入两个同口径影子账户作对照。

“资料与导入”中有8份项目文档、CSV/JSON导入和可编辑字段模板。支持产品、持仓、成交、估值编辑和删除。删除需本人确认；同键再次导入为更新，整批校验后一次保存。

## 技术与启动

复用现有React/TypeScript、Express会话与项目授权、本机FastAPI+SQLAlchemy+SQLite，不另开Streamlit站点、不改Prisma schema。Python用Decimal计算金额，在输出边界转换；没有新增付费依赖。

```powershell
npm run db:seed:investment
npm run dev
```

独立开发命令仍为 `npm run dev:frontend`、`npm run dev:backend`、`npm run dev:compare`。投资计算挂在现有Python服务的 `/investment`，只监听127.0.0.1，Node公开 `/api/investment`。首次运行Python环境沿用 `npm run compare:install`。

### 局域网启动与恢复

```powershell
npm run lan
```

该命令以隐藏后台进程启动三个服务，已有监听端口会保留，不停止其他进程；退出启动终端后服务继续运行。随后检查配置中的前端来源及两个后台健康接口，只有三项均成功才返回0。首次冷启动超过45秒时会返回未就绪，查看 `.tmp/lan-*.log` 后可再次运行。电脑重启后需重新执行，未注册开机自启动；休眠、断网或局域网IP变化仍会中断访问。

当前前端监听 `0.0.0.0:5180`，Node为 `127.0.0.1:3101`，Python为 `127.0.0.1:8001`。已检查Windows当前Public网络中，对应 `C:\Program Files\nodejs\node.exe` 有启用的入站Allow规则，未修改或关闭防火墙。仍需同网络的另一台设备最终确认网络侧可达性；本机验收不覆盖路由器客户端隔离或其他设备策略。

界面路径为 `/invest?project=<id>`，也支持从项目首页直接操作。`tab`和`demo`参数保留视图。数据保存于现有Python数据库的 `investment_records`，包含用户、项目、类型、键和JSON字段；账号与项目联合隔离。项目分享身份不能访问投资私有API，管理员也只看到自己的账本。通用文档由现有内容管理编辑。

## 导入字段

| 类型 | 键 | 必填字段 | 可选及说明 |
| --- | --- | --- | --- |
| 产品 | code | name/category/peer/riskLevel/minMonths/sourceName/sourceUrl/asOf/publishedAt/fetchedAt | 其余费用、收益、回撤、跟踪、信用、解释字段见界面模板；demo导入强制false |
| 持仓 | code | name/category/units/price/cost/asOf | 人民币、非负份额，cost为当前持仓总成本 |
| 成交 | key | date/kind/amount | code/fee/note；kind为buy/sell/deposit/withdrawal/dividend/fee |
| 估值 | date | value | flow默认0；fixedBenchmark/simpleBenchmark可空，空缺不按零 |

类别：etf/equity_fund/bond_fund/money_fund/stock/bond。百分数12表示12%，不是0.12。CSV的holdings/exposures为JSON对象，合计权重不能超过100；按实际披露的部分录入。日期ISO格式，披露和获取时间须含时区。单批1–500行、内容不超过200KB。带演示标记或DEMO代码的产品不能导入真实研究清单。

账户负债字段表示此次保守预留的还款金额，而非自动识别的全部负债；账户净资产只是该口径下的参考。第二至三年支出不重复包含首年。

## 数字边界

- 新增可用现金 = max(0, cash − emergency − expense1y − expense3y − liabilities)。仅在资金和持仓资料可用时生成候选。
- 已有持仓先占用压力亏损预算，再计算每个新候选的研究上界。没有产品档案的持仓按100%损失保守预留；不是实际风险预测。多个候选共享预算，不能相加，压力比例不限制最坏损失。
- 同类规则分主要反映费用与历史回撤；ETF另考虑跟踪误差和折溢价。历史收益不直接用于预测未来，不跨资产类型建立统一赚钱分数。
- 同类组与历史指标区间由导入者核实；首版不会从公告自动辨认统计区间或份额差异。入库前需统一回撤、收益与跟踪误差的观察区间，否则不要使用规则排序作决策。
- 静态费用为恒定本金估算。基金净值通常已扣基金层费用，收益复盘不重复扣费。真实渠道阶梯费率、佣金、持有期与交易限制要在原平台核实。
- 盈亏=期末值−期初值−外部净流入。TWR逐段扣除日终外部流入后连乘；XIRR求日期现金流根，非唯一根不显示。已录追加/提取与估值流入不一致时暂停复盘。
- 估值必须包含现金和持仓，外部流入日需有估值。内部买卖、留在账户的分红不是外部流入。成交记录不自动结算现金和份额；首版采用人工对账快照。
- 基准须同初始金额、流入、日期、费用与风险假设；首期金额不相同拒绝计算。稀疏估值可能低估期间回撤，短期XIRR年化易放大偶然表现。

## 数据与渠道核验

2026-11-13核对：[Tushare接口文档](https://tushare.pro/document/2?doc_id=19)、[上交所ETF资料](https://www.sse.com.cn/assortment/fund/etf/home/)、[巨潮资讯](https://www.cninfo.com.cn/)、[天天基金](https://www.1234567.com.cn/)、[华泰证券](https://www.htsc.com.cn/)。入口可用性不能证明某产品可购或实际费率最优。[中债曲线入口](https://yield.chinabond.com.cn/)此次网页核验超时，保留为研究参考，未声称自动接入成功。

现在支持Tushare授权取数，不自动购买数据权限，不启用DeepSeek或其他外部AI，不调用AKShare未核实接口。规则解释使用用户已核实档案，仅产品数据代码传给行情接口，不上传账户金额、持仓份额、成交或个人信息。七天过期门槛为研究资料复核规则；新行情不会替旧研究资料续期，资料缺失时暂停候选。

本次没有实现全市场历史回测、退市/清盘样本库、券商账户自动对账或自动交易。两组对照通过导入影子账户价值进行同口径复盘，不能据此宣称策略盈利能力已验证。

## 自动更新配置

| 板块 | 自动更新方式 | 有效性要求 |
| --- | --- | --- |
| 基金/ETF对比 | 后台默认每15分钟取数；页面每60秒刷新 | 同一产品完整代码、实际交易日、来源数据日、正数价格、无冲突与异常跳变 |
| 候选解释 | 页面按最新数据重算，最多3项 | 行情与研究资料都有效；无授权/过期/缺失时暂停，不用旧候选冒充新结果 |
| 购买入口 | 每6小时HEAD检查固定官方地址，不跟随重定向 | 可达不等于可购，重定向、拒绝访问、超时分别标记待核实 |
| 收益复盘 | 自动重算已录估值与现金流，另列行情参考估值 | 真实成交、现金、份额仍需对账；估算不写入真实收益记录 |

在本机私有 `.env` 设置，下例中授权值需自行填写，不放入聊天或文档：

```dotenv
TUSHARE_TOKEN=
INVESTMENT_AUTO_UPDATE=true
INVESTMENT_UPDATE_INTERVAL_SECONDS=900
INVESTMENT_REALTIME_ENABLED=false
```

已具有ETF实时接口权限时可将最后一项改为true。服务运行期间每30秒检查配置变化，授权变更会清除旧权限错误的等待时间；不需要重启整站。未配置有效Token时仅官网检查和页面刷新可运行，真实行情状态显示等待授权。当前本机没有配置Token，不能声称已取得授权行情或已验证实际行情准确性。

采用Tushare官方HTTP协议的HTTPS入口 `https://api.tushare.pro`。本次无密钥连通测试返回HTTP200、业务码40101（无授权），仅验证HTTPS可达；授权成功、积分与频次权限仍需实际账号确认。响应错误文本不转发，以免暴露密钥。

- [fund_nav](https://tushare.pro/document/2?doc_id=119)：基金披露净值与复权净值，官方说明每日20:30更新；程序21:30后要求最新开放交易日净值，保留披露宽限期。
- [fund_daily](https://tushare.pro/document/2?doc_id=127)：ETF盘后行情，成交额由千元转换为元；16:30后要求最新开放交易日收盘数据。
- [rt_etf_k](https://tushare.pro/document/2?doc_id=400)：需单独授权；交易时段按60秒尝试，报价源时间超过180秒、缺失或晚于当前时间均失效。这里的60秒是轮询目标，非延迟保证。
- [fund_basic](https://tushare.pro/document/2?doc_id=19)：管理/托管费参考，缓存24小时；不替代平台实际阶梯费率、销售服务费或交易资格。

基金代码与dataCode须一致。ETF可识别5开头为.SH、15开头为.SZ；场外基金不猜测后缀，需填写经确认的完整数据代码。当前只自动跟踪本人已导入的基金/ETF档案；不是全市场自动选品。股票、直接债券仍为观察档案。导入或编辑时不允许写入服务维护的market字段。

全年收益/回撤仅在复权净值覆盖约一年、至少200个样本且无大段缺口时计算，不用未复权单位净值冒充总收益。对比时显示实际观察区间。ETF盘中价格不和昨日净值计算实时折溢价；缺少可核实折溢价时自动候选可能暂停。单期价格变化超过30%进入人工核实，可能是除权或真实极端行情，不自动认定交易机会。

后台在Python服务生命周期运行，网页关闭后继续；服务停止、电脑休眠、断网时停止。缓存保留数据日、源时间、获取时间与最后尝试时间。命中缓存不刷新获取时间，取数失败保留旧值但标记失效；不改写研究文档日期。当前仅支持单个Python worker，未实现跨机器任务锁。
