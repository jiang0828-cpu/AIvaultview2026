# 项目与页面分享

进入任意项目或内容页面后，在页面上方选择：

- **分享项目 / 分享此板块**：接收者可只读浏览该目录及其下属资料、搜索资料和返回目录。重新打开链接并验证密码后，显示最新资料。不会包含个人健康工作区、私人行程列表或其他项目。
- **分享当前页面**：普通资料和单个行程沿用各自的详情展示；其他项目页面保存当前可见内容的只读快照，标注快照时间，不开放其他标签页及编辑操作。内容更新后需要重新生成页面快照链接。

链接格式为 `/s/<16位随机码>`，有效期 30 天。接收者只需输入分享密码，无需用户名，也不会获得普通资料库会话。默认分享密码 `123456` 由现有分享账号维护；更改该密码或禁用分享账号会使既有媒体授权失效。

项目/板块链接和页面快照绑定创建者：创建者被禁用，或失去对应目录访问权限后，链接停止开放内容。单份资料与单行程沿用既有分享规则。管理员、账号及改密页面没有分享入口。

页面快照以结构化节点保存，不接收脚本、事件处理器、任意 HTML、表单密码或项目范围外的本地媒体。页面分享不会触发订阅、数据编辑或外部平台发布。

验收命令：`npm test`、`npm run typecheck`、`npm run lint`、`npm run build`。浏览器检查使用 `scripts/verify-universal-share-browser.mjs`，需本地数据库和开发服务，`FRONTEND_ORIGIN` 必须与后端允许的来源一致。
