# 冬日湖畔旅行配图

使用内置 imagegen 工具生成（非 CLI），表达冬季一家三口的河畔、湖堤与博物馆游览情境。不是景区实拍、真实建筑复原或导航地图，不包含私人日期、行程或预算。

项目资产：`frontend/public/images/winter-lake-roadtrip.webp`，由生成原图使用 sharp 转码压缩。原图保存在 Codex generated_images。图文页按洪泽/柳巷目的地与冬季月份选用，旧行程配图保持原样。
